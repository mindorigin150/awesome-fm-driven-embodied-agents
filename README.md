# Awesome Foundation-Model-Driven Embodied Agents

A curated list of foundation-model-driven embodied agents, starting with harnesses and evaluation.

## Agent Harnesses

- <a id="embodied-harness"></a>**Embodied Harness**: Semantic robot tools built on DeepSeek Harness. [![Code: GitHub](https://img.shields.io/badge/Code-GitHub-2ea44f?style=flat-square)](https://github.com/imakiyui/embodied-harness)
- <a id="ora"></a>**ORA**: Open Robot-Use Agents. [![Code: GitHub](https://img.shields.io/badge/Code-GitHub-2ea44f?style=flat-square)](https://github.com/hao-ai-lab/ORA) [![Website: Blog](https://img.shields.io/badge/Website-Blog-007ec6?style=flat-square)](https://haoailab.com/blogs/ora/)
- <a id="roborsi"></a>**RoboRSI**: Multi-agent harness for robot self-improvement. [![arXiv: 2610.12424](https://img.shields.io/badge/arXiv-2610.12424-b31b1b?style=flat-square)](https://arxiv.org/abs/2610.12424) [![Code: GitHub](https://img.shields.io/badge/Code-GitHub-2ea44f?style=flat-square)](https://github.com/nssmd/RoboRSI)
- <a id="rpent"></a>**RPent**: Agentic Infrastructure for the Physical World. [![arXiv: 2607.08448](https://img.shields.io/badge/arXiv-2607.08448-b31b1b?style=flat-square)](https://arxiv.org/abs/2607.08448) [![Code: GitHub](https://img.shields.io/badge/Code-GitHub-2ea44f?style=flat-square)](https://github.com/RLinf/RPent)
- <a id="sensenova-roborsi"></a>**SenseNova-RoboRSI**: Recursive Self-Improvement for Embodied Agents. [![Code: GitHub](https://img.shields.io/badge/Code-GitHub-2ea44f?style=flat-square)](https://github.com/OpenSenseNova/SenseNova-RoboRSI)
- <a id="show-harness"></a>**Show-Harness**: Just a VLM Agent Can Play Robots. [![arXiv: 2609.10522](https://img.shields.io/badge/arXiv-2609.10522-b31b1b?style=flat-square)](https://arxiv.org/abs/2609.10522) [![Code: GitHub](https://img.shields.io/badge/Code-GitHub-2ea44f?style=flat-square)](https://github.com/showlab/Show-Harness)
